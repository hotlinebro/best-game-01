# TORCHDEEP

A turn-based dungeon crawler for the make.fun best-game-01 competition.

Descend seven floors of a dark dungeon with one torch to keep alive. Explore, fight monsters turn by turn, level up, find gold, potions and torch oil, and slay the Ember King on floor 7. Win by beating the boss; lose when your HP reaches zero.

- **Play:** serve `game/` with any static server and open `game/index.html` in desktop Chrome (or run `node serve.ts`).
- **Controls:** arrows/WASD or tap a tile to move; click or press 1–4 in battle; P pause, R restart, M mute.
- **Design:** see `DESIGN.md`.
- **Tests:** `node tests/regression.mjs` simulates full playthroughs headlessly.
